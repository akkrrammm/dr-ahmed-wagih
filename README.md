# Dr. Ahmed Wagih — Clinic Website

> Official multilingual (Arabic / English) website for Dr. Ahmed Wagih, with a fully dynamic admin dashboard.

🔗 **Live site:** [dr-ahmedwagih.com](https://dr-ahmedwagih.com/)

## ✨ Features

- 🌍 Multilingual Arabic (RTL) & English routing with `next-intl`
- 📄 Pages: Home, About, Services, Articles, Videos, Reviews & Contact
- 🛠️ Admin dashboard to edit every page section, global content and text — no code needed
- 🔐 Secure admin authentication
- 📱 Fully responsive, mobile-first design

## 🛠️ Tech Stack

Next.js (App Router) · React · TypeScript · Tailwind CSS · Prisma · PostgreSQL · Supabase · next-intl

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Add your database and Supabase environment variables to `.env.local` before running.
